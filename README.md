# STUDENT GRADE TRACKER

## Features
- Add student names and scores.

- Automatically calculate grades (A, B, C, D, F).

- Validate user input to prevent invalid names and scores.

- Save student records in a text file (students.txt).

- Read and display previously saved student records.


## How to Run
- Make sure Python is installed.

- Clone or download this repository.

- Open the project folder in your terminal.

Run the program:

```
python main.py
```

- Enter student names and scores when prompted.

- Press Enter on an empty name to finish adding students.


## Built With
- Python 3 – Main programming language.

- Object-Oriented Programming (OOP) – Uses a Student class to organize student data and methods.

- File Handling – Uses text files (students.txt) to store and retrieve student records.


## Data Structures Used
- List – A list (student_list) stores multiple Student objects.

- Objects – Each student is represented by an instance of the Student class.
